# 近传 LanDrop

局域网文件互传 App，**Android + iOS 双端**。两台手机连同一个 Wi-Fi，打开就能互相传文件——不经过服务器、不登录、不限速、不限大小。

> **下载页**：<https://muxin520i.github.io/Landrop/>

---

## 三个 APK 有什么区别

发布页里 Android 有三个 APK，**功能完全一样**，区别只在支持哪些 CPU 架构：

| 文件 | 大小 | 适合谁 | 说明 |
| --- | --- | --- | --- |
| `Landrop-x.y.z-arm64-v8a.apk` | 约 27 MB | 绝大多数手机 | 64 位 ARM。2017 年以后的中高端机型基本都是这个架构，**优先选它** |
| `Landrop-x.y.z-armeabi-v7a.apk` | 约 23 MB | 老手机、低端机 | 32 位 ARM。2016 年前后的旧机型，或部分入门机还在用 |
| `Landrop-x.y.z-universal.apk` | 约 71 MB | 不确定就选这个 | 三种架构（arm64-v8a / armeabi-v7a / x86_64）全打包，任何机器都能装，代价是体积大了近两倍 |

挑不准的话直接下 `universal`，装上去一样用；装错了系统会提示「应用未安装」或「解析包出错」，换另一个装就行，不会损坏数据。

> 手机上查架构：设置 → 关于手机 → 处理器，写 `arm64` / `64 位` 的选 `arm64-v8a`，写 `armeabi-v7a` / `32 位` 的选 `armeabi-v7a`。

iOS 的 ipa 同样带版本号（`Landrop-1.1.0-unsigned.ipa`）。签名工具里出现多条「近传」，那是它保存的多个 ipa 文件，不是装了多个 App——bundle id 都是 `com.landrop.app`，同一个证书签出来的包装到手机上会直接覆盖旧版，桌面上始终只有一个图标。

## 功能

| 能力 | 说明 |
| --- | --- |
| 设备发现 | 打开 App 自动搜一次（约 2~4 秒）；之后点「搜索」手动查找，不常驻扫网段 |
| 任意文件 | 照片、视频、文档、压缩包、APK 都可以，支持多选 |
| 大文件 | 2 MB 分片传输，显示实时速度与剩余时间；断线后从断点续传，不用从头再来 |
| 文字和链接 | 输入框直接打字或粘贴，对方点一下即复制，不用为一段验证码建文件 |
| 设备名 | 设置里改成「我的手机」，两台同型号也分得清 |
| 自动存相册 | 收到的照片视频直接写进系统相册，开关在设置里 |
| 聊天式界面 | 收发记录按时间线排列，像聊天一样，点一下就能打开/导出；长按可清除单条 |
| 扫码连接 | 自动发现失败时，扫对方「我的连接码」即可直连 |
| 手动 IP | 最后兜底，输入 `192.168.1.5` 这种地址 |
| 版本检查 | 设置页打开即查 GitHub 最新版本，有更新直接跳发布页下载 |
| 电脑浏览器 | 同一个 Wi-Fi，电脑打开 `http://手机IP:53318` 就能双向传，不装客户端。电脑传手机：拖进去；手机传电脑：设备条选「电脑网页」，网页上点保存 |

传输全程走局域网直连，没有任何云端中转，也没有账号体系。

## 使用

1. 两台手机连**同一个 Wi-Fi**（注意别开「AP 隔离 / 访客网络」，这类网络设备之间互相不通）
2. 各自打开「近传」——打开后会自动搜一次附近设备，约 2~4 秒
3. 没看到对方就点设备条最左边的「搜索」再搜一次；设备出现后点一下选中
4. 传文件：点底部 `+` → 选「文件」或「照片或视频」→ 选完自动开始传
5. 传文字：在输入框直接打字或粘贴，点右侧箭头发送；对方点一下即复制
6. 接收方在聊天流里看到文件，点一下 → 系统分享面板 → 存到相册 / 文件 / 发给别人
7. 想清掉某条记录，**长按那条消息**即可；只清记录，不会动文件
8. 电脑传文件：手机和电脑连同一个 Wi-Fi，在手机「设置 → 电脑访问」里看到地址，电脑浏览器打开它——拖文件进去就是传到手机；点文件右边的「下载」就是存到电脑。手机要保持在 App 前台
9. 手机传电脑：电脑网页开着的时候，手机设备条最右边会出现一台「电脑网页」，点它，再选文件发送——电脑网页顶部会弹出「手机发来的」，点「保存」就落到电脑上。文字和链接也一样，点「复制」即可

> 首次打开会弹「是否允许访问本地网络」，必须点允许——iOS 靠这个权限才能发现另一台手机。

### 接收的文件存在哪

| 平台 | 位置 |
| --- | --- |
| Android | `Android/data/com.landrop.app/files/Received/`（App 内点文件可直接分享导出） |
| iOS | App 沙盒 `Documents/Received/`，已开启文件共享，可在「文件」App → 我的 iPhone → 近传 里看到 |

## 已知限制

- **AP 隔离网络不可用**：酒店、校园网、公司访客 Wi-Fi 常开启客户端隔离，设备之间无法互通，此时扫码也连不上。用自己的手机热点即可。
- **iOS 后台会挂起**：传输时请保持 App 在前台（已用 wakelock 防止息屏，但切到别的 App 仍可能断）。断了重试会自动续传。
- **不常驻搜索**：为了省电，App 只在打开时和手动点「搜索」时扫描网段。对方后打开的 App，需要你点一下「搜索」才会出现。
- **两台 iPhone 的设备名可能相同**：iOS 16 起系统不返回用户自定义设备名，App 用名称 + 4 位短码区分。

## 它是怎么工作的

设备发现走 /24 网段的 TCP 探测，不用 UDP 组播——iOS 14 起组播收发需要 Apple 单独审批的 entitlement，很多局域网工具在 iOS 上「搜不到设备」就是这个原因。传输走 HTTP 分片上传，2 MB 一片；断线重连时先问对端已收到多少字节，再从那里续上。

- 只在局域网内通信，没有服务器、没有账号、没有埋点
- 接收端默认自动接收同一 Wi-Fi 内发来的文件（自用场景省一次确认），不要在公共 Wi-Fi 下开着它传敏感文件
