安装步骤

Android 直接装

  1. 下载 apk：点上面的按钮，得到 landrop-app-release.apk。
  2. 点击安装：系统提示「未知来源」时，选择允许本次安装。
  3. 打开授权：首次启动同意文件访问与本地网络权限。
  4. 连同一个 Wi-Fi：两台手机接入同一网络，打开 App 就能看到对方。

iOS 需自签

  1. 下载 ipa：点上面的按钮，得到 Landrop-unsigned.ipa，不用解压。
  2. 电脑装 Sideloadly：Windows 或 macOS 都行，从 sideloadly.io 下载。
  3. 手机连电脑：数据线插上，解锁，弹「信任此电脑」时点信任。
  4. 拖进 Sideloadly：填自己的 Apple ID，点 Start 等进度走完。
  5. 信任证书：设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。
  6. 打开开发者模式：iOS 16 以上，设置 → 隐私与安全性 → 开发者模式 → 打开并重启。

iOS 免费签名的包 7 天到期，重新签一次覆盖安装即可，App 里的记录不会丢。

常见问题

两台手机都装了，但上方看不到对方

先确认两台手机连的是同一个 Wi-Fi。很多路由器默认开了「AP 隔离」，会阻断设备互访，去路由器后台关掉。实在连不上，点右上角扫码，或手动输入对方的 IP 和端口。

Android 装新版提示「应用未安装」或签名冲突

说明手机上还留着早期测试包的旧签名。卸载旧版再装这次的新版即可，之后所有版本都用同一把钥匙签名，可以直接覆盖升级。

iOS 过了几天突然打不开

免费 Apple ID 的签名有效期是 7 天。用 Sideloadly 重新签一次、覆盖安装就行，本地数据会保留。

传输会不会走流量、经过服务器

不会。两个设备在同一局域网内直接建立连接，文件只在这两台手机之间流动，不经过任何服务器。速度取决于路由器，通常比蓝牙快一个数量级。

为什么不上架 App Store

局域网互传需要在本地网络里监听端口、后台维持传输，这类能力和 App Store 的审核口径冲突，所以走自签分发。所有文件都只存在你自己的设备上。
